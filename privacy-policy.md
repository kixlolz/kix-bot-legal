# Kix Development Bot — Privacy Policy

**Last Updated:** October 8, 2026

This Privacy Policy explains how the **Kix Development** Discord bot collects, uses, and stores data.

---

## 1. Data We Collect

The Bot may collect and store:

| Data Type | Purpose |
|-----------|---------|
| Server IDs | Identify which server the Bot is in |
| Channel IDs | Send messages to the correct channels |
| Role IDs | Manage permissions and access |
| User IDs | Track tickets, moderation actions, and verification |
| Message content | Only when required for tickets, AI assistant, or auto-moderation |
| Configuration data | Custom settings per server |
| Command usage | Owner audit logs |

---

## 2. How We Use Data

Data is used only to:

- Provide Bot features
- Log moderation actions for staff
- Handle ticket systems
- Manage verification and roles
- Answer user questions via the AI assistant

We do **not**:

- Sell data to third parties
- Use data for advertising
- Share data with anyone outside of the Bot's operation

---

## 3. Data Storage

Data is stored securely in a private database controlled by Kix Development.

- Data is not accessible to the public
- Data is not shared with unauthorized users
- Data is retained only as long as needed for Bot functionality

---

## 4. Third-Party Services

The Bot uses the following third-party services:

- **Discord API** — to function within Discord
- **Groq API** — for the AI assistant feature (only for messages in the designated AI channel)
- **Cloudflare** — for tunnel/security services

These services have their own privacy policies.

---

## 5. User Rights

You have the right to:

- Request deletion of your data
- Ask what data we have on you
- Opt out of using the Bot

To request data deletion, contact **Kix** on Discord: `wwwivlol`

---

## 6. Data Retention

- Ticket transcripts are kept for reference
- Moderation logs are kept for server security
- AI messages are not permanently stored
- Config data is kept until removed

---

## 7. Security

We take reasonable steps to secure data:

- Encrypted connections (HTTPS)
- Private database access
- Limited access to only the Bot owner

However, no system is 100% secure. Use the Bot at your own risk.

---

## 8. Children's Privacy

The Bot is not intended for users under the age of 13 (or the minimum age required by Discord in your region).
